# KAUPUNKI UI art and fonts (T03)

Teak & bakelite 1960s radio/desk look (approved `art/explore/mockup_C.png`): dark top bar, teak side panel with
a brass name plate, cream bakelite keys with 13x13 ink pictograms, a paper plaque with the President, a
brass-bezelled minimap, a dark news ticker, dark-brown bakelite windows with paper interiors.

Everything is generated by `art/gen_ui.py` (deterministic, Pillow only):

```
python3 art/gen_ui.py            # writes the BMPs, art_ui.h, ui_layout.h, previews, and this file's inventory block
python3 art/gen_ui.py --check    # + self-check: 24-bit BI_RGB, width <= 640, no near-key pixels, all colours
                                 #   565-rounded, unique names, every glyph in every font, every icon listed here,
                                 #   layout fits all three resolutions, key labels fit, headers ASCII
```

| File | What |
|---|---|
| `ui_frame.bmp` | frame pieces, 9-slices, buttons, controls, lamps, cursors |
| `ui_icons.bmp` | 13x13 pictograms, each also as `_off` (greyed) |
| `ui_pres.bmp` | President portraits (2 sizes x 4 moods), newspaper masthead, rubber stamps |
| `font_body.bmp`, `font_head.bmp` | glyph atlases (all font variants of one size in one sheet) |
| `art_ui.h` | `art_ui_sheets[]`, `art_ui_fonts[]` exactly per `src/art.h` (only art.cpp includes it) |
| `ui_layout.h` | `ui_layouts[3]` frame rects for 640x480 / 800x600 / 1024x768 + `UI_COL_*` colours (for ui.cpp) |
| `preview_ui/` | `frame_<W>.png` (full frame + panels, fly-out, tooltip), `frame_<W>_clean.png`, `zoom_panel_800_2x.png`, `icons_review_3x.png`, `fonts_1x/2x.png`, `president_3x.png`, `newspaper_640.png`, `sheet_*_3x.png` |

All sheets: keyed (RGB 255,0,255 transparent), `ART_ZOOM_ANY`, anchors 0,0 (except `cursor_hand` = hotspot 4,0),
hotspots -1. Total UI VRAM about 655 KB (MaxRects-packed) (see `--check` output). Opaque pieces simply contain no key pixels.
Sprite names do not collide with T02's world names (no `ovl_`, `cur_`, `zone_` prefixes here).

## Composing the frame (for T09)

Use `ui_layouts[]` from `ui_layout.h` (pick the entry whose `scr_w` matches). Compose each part into a VRAM cache
target once and again only when its content changes (probe 7); every piece below is a plain keyed blit.

1. **Top bar** (`top`, 16 px): tile `bar_tile` (32x16) across. Fields left to right, separated by `bar_sep`
   (2x12 at y=2, leave 2 px either side): date on `cal_plate` (3-slice, 12 tall at y=2; text `body_dark` at
   +6, y=2), captions in `body_brass` at y=3 ("Funds", "Population", "Demand", "Approval"), values in
   `body_light` on a recessed `bar_well` (3-slice, 12 tall at y=2, text at +4, y=2), deltas `body_green_lt` /
   `body_red_lt`. Demand: `dem_well` (19x13 at y=1); zero line is row 6 of the well; per bar (R, C, I at
   x+2, x+7, x+12) blit `dem_bar_r|c|i` rows 0..v-1 upwards ending at well row 5 for +v (v <= 5) or downwards
   from row 7 for -v. Speed keys at `speed` (15x12; then +w+`speed_gap` each): `speed_pause|1|2|3_normal|hover|on`
   (`on` = the active speed, amber "lit" key). Menu: `speed_menu_normal|hover|pressed` at `menu_key`.
   **Zoom keys (F2, DESIGN 14.4):** `btn_zoom_out_<state>` at `zoom_key`, `btn_zoom_in_<state>` at
   `zoom_key.x + w + speed_gap` (15x12 each, same bakelite as the speed keys, magnifier with -/+); states
   `normal|hover|pressed|disabled` (`disabled` = already at that zoom: 32 for out, 64 for in). `zoom_key` sits 6 px
   left of the pause key, so the field limit of the bar becomes `zoom_key.x - 6` (instead of `speed.x - 6`); at
   640 the fields up to the Demand gauge still fit (`preview_ui/frame_640.png`). Tooltips: "Zoom in (+)" /
   "Zoom out (-)", Z toggles.
2. **Panel** (`panel`): tile `teak_tile` (144x128, seamless vertically; blit the left `panel.w` columns), then
   `panel_edge` (3x32) tiled down the left edge.
   - `plate`: `plate` 3-slice (16 tall); town name in `head` centred, line top at plate.y+1.
   - Tool keys: 2 columns x 5 rows from `keys` (x, y, key w, key h), gaps `key_gap_x/y`. Each key = `btn_<state>`
     9-slice + `icon_<name>` + label (`body_dark`; `body_grey` and `icon_<name>_off` when disabled). Icon at
     x + (w-1-13)/2, y + 2 + (h-24)/3; label line top at y + h - 13 (both +1,+1 when pressed/selected).
     Order: Roads, Homes, Shops, Industry, Power, Water, Services, Parks, Bulldoze, Query (labels in the previews
     fit all sizes; keep labels <= 8 characters at 640).
   - `tool_label`: active tool / variant name in `body_shadow`.
   - `plaque` 9-slice; `pres_frame_s|l` at `portrait_frame`; portrait `pres_s_<mood>` (32x40) or `pres_l_<mood>`
     (64x80, when `portrait_large`) at `portrait`; "President" + player name (2 lines, `body_dark`) at `pres_name`;
     quote in `body_red` wrapped to `quote.w`, 10 px line pitch, at most `quote.h / 10` lines (2 small, 3 large).
   - Mini keys (`mini`, `mini_count` = 5, x step w + `mini_gap`): `btn_*` 9-slice + centred 13x13 icon, no label.
     Suggested: `budget`, `population`, `overlays`, `undo`, `redo` (tooltips name them).
   - `grille`: decorative radio speaker slots: `grille` 3-slice (5 tall) at x+6, width w-12, every 8 px from y+2;
     the middle slot is replaced by the brass `badge` (centred). Purely cosmetic, compose once.
   - `mmap_frame`: `mmap` 9-slice brass bezel (3 px); the minimap image goes at `mmap` (128x128 at 800/1024,
     88x88 at 640: either a scaled `render_minimap` call or a window that follows the camera). Camera view
     marker: the four 5x5 L-brackets `mmap_cam_tl|tr|bl|br` at the view rectangle's corners (4 blits per frame,
     cheaper than recomposing).
3. **Ticker** (`ticker`, 14 px, map width only): tile `ticker_tile`; per item a severity lamp (7x7 at y+4):
   SEV_INFO `lamp_info` + `body_light`, SEV_WARN `lamp_warn` + `body_amber`, SEV_URGENT `lamp_urgent` +
   `body_red_lt`, SEV_POLITICAL `lamp_pol` + `body_blue_lt`; text line top at y+2. `lamp_off` for an empty ticker.
4. **Map view** = `map`; `ui_map_rect()` returns it.

### Windows (panels)

`win` 9-slice: dark bakelite frame, paper interior. Title band = the 19 px top edge: title in `head_light` at
(x+8, y+3), close button `close_normal|hover|pressed` (13x13) at (x+w-19, y+3). Interior (paper) starts at
(x+6, y+19) and ends 6 px before the right edge and 7 px before the bottom: so a panel of W x H has
(W-12) x (H-26) usable paper. The centre piece `win_c` is a flat paper tile; for big panels you may instead
`gfx_fill` the interior with `UI_COL_PAPER` (identical colour) to save blits. `paper_tile` (32x32) is an
optional subtle fibre texture. Any size from about 40x40 up works (320x400, 600x420 tested in previews).

Inside panels:
- `tab_normal|hover|selected` (3-slice, 14 tall, index-card tabs): place in a row at interior y+4, 1 px apart,
  label `body_dark` at +6, +2; draw `tab_line` (1 px pencil) along the tab baseline under the non-tab parts.
- `slider_track` (3-slice, 7 tall) with `slider_fill` (same shape, amber) for the value part, knob
  `slider_knob_normal|hover|pressed` (9x13) centred on the value, knob top = track top - 3.
- `check_on|off_normal|hover|disabled`, `radio_on|off_...` (11x11); label at +16.
- `arrow_up|down|left|right_normal|pressed|disabled` (11x11), `sbar_track` / `sbar_thumb` vertical 3-slices (11 wide).
- `inset` 9-slice (recessed aged paper) for numbers, lists, graphs; `rule` (16x2 tile) engraved divider.
- Text buttons: `btn_<state>` 9-slice (20 px tall reads well), centred `body_dark` label.
- Stamps: `stamp_decree`, `stamp_approved`, `stamp_rejected`, `stamp_seal` (17x17 round "§"), `stamp_project`
  (letter-spaced "PROJECT", title-screen logo above the scaled "LÄHIÖ", R1).

### Buttons / keys

`btn_normal|hover|pressed|disabled|selected` 9-slices (corners 3/3/4/4, tiles 16). The last row and column of
every key are a teak-coloured drop shadow, so the visible face is (w-1) x (h-1): centre content on w-1, h-1.
`pressed` (momentary) and `selected` (active tool, warm amber "lit bakelite") are inset: shift content by +1,+1.
`disabled`: greyed face; use the icon's `_off` variant and `body_grey` text.

### Fly-outs and tooltips

- Fly-out: `fly` 9-slice (dark bakelite rim 3 px, cream face) left of the panel, right edge about 4 px left
  of `panel.x`; `fly_arrow` (6x11, points right) at the fly-out's right edge level with the key centre. Rows
  17 px tall from y+6: icon 13x13 at (x+8, row+2), name `body_dark` at (x+25, row+3), cost right-aligned at
  x+w-8; hover row `flyrow_hover` 3-slice (x+4, width w-8), current choice `flyrow_sel`; locked rows use
  `icon_*_off` + `body_grey` and show "Unlocks at: ..." instead of the cost. `fly_sep` (16x2 tile) between groups.
- Tooltip: `tip` 9-slice (index card, 1 px ink border, 1 px shadow on the right/bottom; the last row/column is the
  shadow): text `body_dark` at (x+6, y+3), 11 px line pitch; use GLYPH_ARROW_UP/DOWN/BULLET for itemised lines,
  `body_red` / `body_green` for negative / positive amounts.
- Cursors (if the game draws its own): `cursor_arrow` (hotspot 0,0), `cursor_hand` (anchor = hotspot 4,0).

## Fonts

Hand-drawn proportional pixel fonts. Every font has the same 125 glyphs: codes 1-5 (GLYPH_CHECK, _CROSS, _BULLET,
_ARROW_UP, _ARROW_DOWN), ASCII 32-126, and Latin-1/cp1252 `Ä Ö Å ä ö å É é Ü ü § ° ½ · × « »`, en dash 0x96 (use as
minus), em dash 0x97, quotes 0x91-0x94 (Finnish quotes use 0x94 on both sides), ellipsis 0x85, bullet 0x95.
Any other code: draw `?`. Glyph tables are sorted by code; build a 256-entry lookup at init.

| Font | Size | Use |
|---|---|---|
| `body_dark` | body | text on paper / cream keys |
| `body_light` | body | values on the dark top bar, ticker info |
| `head` | head | panel section titles, brass plate, newspaper (ink) |
| `head_light` | head | window title bands |
| `head_red` | head | stamps, decree headings |
| `body_grey` | body | disabled / secondary text |
| `body_red`, `body_green` | body | negative / positive amounts, missing / met requirements (on paper) |
| `body_amber`, `body_red_lt`, `body_blue_lt` | body | ticker warning / urgent / political (on dark) |
| `body_brass` | body | top bar captions |
| `body_green_lt` | body | positive deltas on the dark bar |
| `body_shadow` | body | cream text with a 1 px dark shadow (labels on teak or over the map) |
| `float_light`, `float_green`, `float_red` | body | 1 px ink outline: floating "-450 mk" over the map |

Metrics: **body** line height 11, baseline 9 (caps on rows 2-8 of the line, x-height 5, descenders rows 9-10,
capital accents rows 0-1); digits are tabular (advance 5); space advance 3; letter spacing is in the advance.
**head** line height 14, baseline 11 (9 px caps on rows 2-10, 2 px stems, descenders rows 11-13).
`ui_text(x, y)`: y is the line top; for each byte look up the glyph, blit its rect at (pen + ox, y + oy), pen += adv.
Shadow/outline fonts have bigger rects (ox, oy = -1 for outline) but the same advance as the plain font. Suggested
paragraph pitch: 11 (body, tight), 12 (body, relaxed), 15 (head). Numbers: text.h uses "12,500 mk".

## President, newspaper, stamps

- `pres_s_<mood>` 32x40 (plaque), `pres_l_<mood>` 64x80 (plaque at 1024x768, panels, newspaper, event cards),
  moods `content`, `stern`, `delighted`, `worried` (suggested mood ids 0-3 in that order for
  `ui_president_say` / `text_president_line`). Tall bald dome, round glasses, big ears, grey temples, dark suit,
  white shirt, dark red tie; affectionate caricature, no real likeness or photo. Keyed: put them on
  `pres_frame_s|l` (or any background).
- `masthead` 600x54: "Maakunnan Sanomat" (made-up provincial daily) in a thresholded bold Didone (rendered from the
  Mac's Bodoni 72 at generation time; falls back to the 2x headline font), double rules and the tag line
  "INDEPENDENT PROVINCIAL DAILY · FOUNDED 1919". Ink only (keyed): draw on any paper colour. Under it T09 draws the
  issue/date line (`body_dark`), `rule_news` (16x4 tile: thick + thin rule), headlines in `head` (pixel-doubled
  for the main one looks right, see `preview_ui/newspaper_640.png`), body text `body_dark` in 3 columns.
- `stamp_decree` ("§ DECREE / BY ORDER OF THE PRESIDENT"), `stamp_approved`, `stamp_rejected`, `stamp_seal`, `stamp_project`:
  red rubber stamps with deterministic wear, keyed.

## Colours

`ui_layout.h` defines `UI_COL_<NAME>` as `r, g, b` (565-rounded) for fills between pieces, e.g.
`gfx_fill(x0, y0, x1, y1, gfx_rgb(UI_COL_PAPER))`. Palette source: STYLE.md 6 "UI" + muted THEME 7.2 accents.

## Notes and limitations

- Å is drawn with its ring merged into the A's apex (only 2 accent rows above the caps); fine in context.
- No typewriter font yet (letters/decrees in v1.0 can use `body_dark` on paper with `head_red` stamps).
- The masthead depends on a Mac system font at generation time; the committed BMP is what the game uses.
- Grown zone buildings have no individual icons (the query panel can show `z_<zone>`); add `b_<key>` icons in
  `ICONS` if wanted (anything 13x13; `icon_ol()` adds an ink outline around filled shapes automatically).
