# Project Lähiö

*A Finnish town, 1955-1990.* (Working title: KAUPUNKI.)

An isometric sandbox city builder for **Windows 98**, set in **Finland from 1955**: post-war reconstruction,
wooden *rintamamiestalo* suburbs giving way to concrete *lähiö* estates, lakes and forests, sawmills and paper mills,
saunas, emigration to Sweden and clearing trade with the big neighbour in the East. You are the **President**
(you choose the name): officially above politics, in practice deciding where every new suburb goes.

Classic grid building (roads, zones, power, water pipes, services, budget) designed with lessons from modern city
builders: every number is explained, effects are previewed before you build, undo works within the month, and the
simulation is aggregate and deterministic, with cosmetic traffic and smoke on top.

Status: **Version 1.0** (2026-11-05). One presidency from 1955 to 1990 (about 30 minutes at speed 3, 2.5 hours at
speed 1), ending with the 1990 newsreel; the sandbox continues afterwards. Includes politics (decrees, letters, event
cards, elections), industry kinds with forestry and farms, the paper mill and Valtion Metalli, traffic congestion and
buses, water pipes and district heating, element-built apartment blocks, clearing trade and the oil shocks, and a
newspaper that quietly advises the President.

**Download:** see the GitHub Releases page for `lahio-1.0.zip` (unzip anywhere on a Win98 machine and run `lahio.exe`).

## System requirements

| | Minimum (tested) | Target hardware |
|---|---|---|
| OS | Windows 98 SE | Windows 98 SE |
| CPU | Pentium II 233 MHz | GHz-class Pentium M (IBM ThinkPad X41 / T40 class) |
| RAM | 128 MB (game uses ≤ 40 MB incl. winter art) | 512 MB+ |
| Video | DirectDraw with hardware blits, **16 MB video memory**, 16-bit colour | 16 MB+ with a native Win98 driver |
| Resolution | 800x600x16 fullscreen (640x480 and 1024x768 options, `-window` for windowed) | same |
| DirectX | 6.1 runtime or newer (DirectDraw, DirectSound) | 6.1+ |
| Sound | DirectSound device (optional: the game runs silently without one) | |

Measured on an 86Box VM (Pentium II 233, Voodoo3 16 MB, Win98 SE): 60 fps scrolling a 24,000-resident city at
640, 800 and 1024; automatic drop to 30 fps if the simulation needs the CPU. See `docs/PERF.md`.

## Building

The game is written in pre-standard C++ for **Microsoft Visual C++ 6.0** and built inside Windows 98:

```
nmake                    (in the project folder, after VCVARS32.BAT)
```

Development setup used here: the source lives on a Mac and is shared to Win98 as drive `M:`; builds and runs are
driven remotely (`vmb/w98 build lahio`, project folder `dev/lahio` = `M:\dev\lahio`). The portable simulation modules also build on macOS/Linux with clang
for fast unit tests:

```
make -f tests/Makefile.mac
```

Art and sound are generated by deterministic scripts (Python 3 + Pillow): `python3 art/gen_art.py`,
`python3 art/gen_ui.py`, `python3 tools/make_sfx.py`. The generated BMP sheets and WAVs are committed so the game
runs without Python.

## Running

`lahio.exe` (fullscreen 800x600). Options: `-window`, `-res 640|800|1024`, `-fps 60|30|auto`, `-seed N`,
`-load FILE`, `-script FILE` (replay tool commands; with `-fast` headless), `-bench N` (writes `bench.txt`),
`-log FILE` (default `lahio.log`). Settings are saved in `LAHIO.INI` (section `[Lahio]`); a `KAUPUNKI.INI` from
the working-title builds is read once and copied into `LAHIO.INI`.

Save games keep the working title's format: `*.KAU` files with the internal magic `KAUP`, so towns saved before the
rename still load.
